PGPM @VERSION@

OpenPGP keys and messages, as a native Mac app written in Rust. Setup installs PGPM in your Applications folder.

PGPM uses GnuPG for all encryption and for hardware keys (Nitrokey, YubiKey). If GnuPG isn't on this Mac yet, Setup downloads GPG Suite from gpgtools.org (an internet connection is needed), checks the download, and opens its installer: finish it to start using PGPM.
